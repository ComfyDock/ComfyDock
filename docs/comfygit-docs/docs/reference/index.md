# Reference

Reference pages are for exact shapes, commands, and boundaries. They are less
narrative than the Get Started pages and are meant for users who already know
which part of ComfyGit they need to inspect.

## Available Reference

- [CLI reference](../cli-reference/global-commands.md) summarizes the current
  `cg` command surface.
- [Manager reference](manager.md) describes what the ComfyGit Manager custom node
  owns inside ComfyUI.
- [Manifest reference](manifest.md) describes the portable environment recipe.
- [Workflow contract reference](workflow-contracts.md) describes saved workflow
  input/output contracts.
- [Serve API reference](serve-api.md) lists the local `cg serve` HTTP surface.

For task-oriented guidance, start with [Get Started](../getting-started/overview.md).
