# Collaboration Guides

Collaboration guides cover sharing a ComfyGit environment with teammates,
containers, or other machines.

## Start Here

- [Export and import](export-import.md) covers portable archive handoff.
- [Git remotes](git-remotes.md) covers branch-based collaboration.
- [Materialize runtime environments](materialize.md) covers non-interactive
  hydration for containers, CI, and runtime machines.
- [Team workflows](team-workflows.md) covers practical collaboration patterns.

Before handing off an environment, commit the portable state and make sure
required model dependencies have source information.
