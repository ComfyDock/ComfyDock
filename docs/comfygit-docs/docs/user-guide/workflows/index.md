# Workflow Guides

Workflow guides cover tracked ComfyUI workflow files, dependency resolution,
manual model dependencies, and contract authoring.

## Start Here

- [Workflow tracking](workflow-tracking.md) explains how editable workflow JSON
  becomes portable environment state.
- [Workflow resolution](workflow-resolution.md) covers node and model dependency
  analysis.
- [Model dependencies](model-dependencies.md) explains manually declaring models
  a workflow needs.
- [Workflow contracts](workflow-contracts.md) covers saved input/output shapes
  for Studio and API execution.

Use workflow contracts when a workflow should become a stable interface instead
of just an editable ComfyUI graph.
