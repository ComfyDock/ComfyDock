# Serve And Studio Guides

Serve and Studio guides cover turning saved workflow contracts into a local UI
and HTTP API.

## Start Here

- [Serve workflows](serving-workflows.md) explains the `cg serve` runtime.
- [Uploads and file refs](uploads.md) explains how media files move through the
  serve API.

`cg serve` fronts an already running ComfyUI server. Start ComfyUI with `cg run`
first, then serve the saved contracts for that environment.
