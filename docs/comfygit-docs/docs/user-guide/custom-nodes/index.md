# Custom Node Guides

Custom node guides cover installing, developing, updating, and troubleshooting
ComfyUI extensions inside a ComfyGit environment.

## Start Here

- [Adding nodes](adding-nodes.md) covers registry and Git node installs.
- [Development nodes](development-nodes.md) explains local checkout linking.
- [Managing nodes](managing-nodes.md) covers status, updates, and removal.
- [Node conflicts](node-conflicts.md) explains dependency and identity issues.

Use ComfyGit commands or Manager actions for node changes so the environment
manifest stays reproducible.
