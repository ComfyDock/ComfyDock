# Environment Guides

Environment guides cover the lifecycle of a managed ComfyUI installation: create
it, run it, keep it synced, repair drift, and preserve useful history.

## Start Here

- [Running ComfyUI](running-comfyui.md) explains the normal `cg run` flow.
- [Sync and repair](sync-and-repair.md) explains how ComfyGit reconciles runtime
  state with the manifest.
- [Local runtime config](local-runtime-config.md) covers hardware-specific and
  machine-local settings.
- [Environment history](version-control.md) covers commits, branches, merges,
  and rollbacks.

For a first environment, use [Create an environment](creating-environments.md).
